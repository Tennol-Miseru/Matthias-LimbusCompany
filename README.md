一把层层包装的莱瓦汀，一个听见你在公屏呼唤，就会从天而降找你算账的马蒂亚斯。

亲手拆开莱瓦汀的包装，在横扫、穿刺、投掷处决与大力劈砍之间切换。用四段重踏追击敌人，甚至可以破开正面举盾的防御。

完全解放之后，高温会逐渐累积。别忘了留意你的高温计量表。

当然，你也可以在公屏呼唤马蒂亚斯。重复呼唤会逐步提高他的怒火；如果一条消息里同时命中多个不同类别的关键词，他可能直接带着完全解放的莱瓦汀从天而降。

他有自己的战斗
AI、紫色反击阶段、追击飞踹、披风、语音，以及一套完整的战斗机制。

还有一本复仇账簿，可以在你受到致命伤害时救你一次，并让你拥有过人的毅力。

## 马蒂亚斯召唤关键词

在公屏发送以下关键词即可呼唤马蒂亚斯。关键词按类别计算；同一类别中的多个异写在同一条消息中只计为一个类别。

  类别           支持的关键词
  -------------- ------------------------------------------------------------
  姓名           `马蒂亚斯`、`马提亚斯`、`馬蒂亞斯`、`馬提亞斯`、`Matthias`
  称号           `中指`
  组织           `蜘蛛巢`
  毅力相关       `毅力哇啦`、`毅力瓦拉`、`毅力哇拉`、`毅力瓦啦`
  伊利哇啦相关   `伊利哇啦`、`伊利瓦拉`、`伊利哇拉`、`伊利瓦啦`
  人物           `良秀`

### 召唤规则

-   单条消息命中一个关键词类别：马蒂亚斯的怒火提高一级。
-   单条消息命中两个或更多不同类别：直接触发完全解放登场。
-   同一类别的多个关键词异写不会重复计数。
-   `Matthias` 不区分大小写，并支持全角英文字母形式。
-   `中指`
    可以单独作为呼唤关键词；与其他有效关键词同时出现时，也会计入一个独立类别。
